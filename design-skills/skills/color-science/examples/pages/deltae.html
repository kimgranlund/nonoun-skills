Choosing a metric

  • ΔE_ok — modern default for design-token work, palette differentiation, theming. OKLab-based; perceptually uniform; near-zero hue distortion.
  • ΔE2000 — gold standard for color-science / print / textile compliance. Includes rotational hue-rotation term. Use when publishing or auditing reference results.
  • ΔE76 — Euclidean in CIELAB. Ubiquitous, fast, but perceptually uneven (the blue region is over-weighted). Use for back-compat only.
  • HyAB — hybrid metric robust against very large color differences where Euclidean ΔE76 collapses. Niche but useful.
  • ΔE94 — legacy graphic-arts default; ΔE2000 superseded it in 2001.
