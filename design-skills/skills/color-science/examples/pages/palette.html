How it works

    
// For each pixel: encoded sRGB → linear sRGB → XYZ → OKLab
const oklabPixels = imagePixels.map(p =>
  oklab.fromXYZ(srgb.toXYZ(srgbTransfer.decode(p)))
);

// k-means with k-means++ initialization
const { palette } = quantize(oklabPixels, { k: 5, seed: 42 });
// palette is OKLab[] — convert back for display


    

      Using OKLab as the clustering space matters: in RGB, two perceptually-
      similar yellows might be Euclidean-distant, while two perceptually-
      different greens might be close. OKLab's perceptual uniformity makes
      k-means find the right clusters.
