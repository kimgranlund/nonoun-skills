Chromatic adaptation (Bradford CAT)

Drop an image and see how it would look under a different illuminant — the Bradford chromatic adaptation transform takes an image's XYZ values and re-renders them assuming a different light source. Tungsten goes orange-brown; cool fluorescent goes slightly-blue-gray.

What the Bradford CAT is doing

Bradford transforms XYZ from a source white point to a destination white point via "Bradford cone response" — a 3 × 3 matrix approximation of human cone sensitivities. The classic chain: M_Br · Xsrc  →  scale by white-point ratio  →  M_Br−1 · result.

This is the standard for ICC profile work and CSS Color 4. When you see a "P3 → sRGB fallback" that crosses white points (P3 is D65, ICC PCS is D50), Bradford is what's actually moving the chromaticities.
