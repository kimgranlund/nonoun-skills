The math

All values above come from the same source OKLCh triple. The composition pipeline:

// Single source of truth
const src = oklch(L, C, h);

// One conversion per target — every space module exports `toXYZ` and `fromXYZ`
const xyz   = oklchSpace.toXYZ(src);
const lab   = oklab.fromXYZ(xyz);
const cielabVal = cielab.fromXYZ(xyz);
const linRGB = srgb.fromXYZ(xyz);
const encoded = srgbTransfer.encode(linRGB);
const hexStr  = toHex(encoded);
