Exercises to try

  • Simultaneous contrast. Set all squares to the same lightness (L ≈ 0.6). Now drop the inner square's chroma to 0; raise the outer square's chroma. Watch how the inner gray takes on a slight color cast opposing the outer.
  • One-as-two. Use only 3 squares (toggle squares="3" if you build it that way). Set outer dark and inner pale, then put mid1 between them. The mid1 reads dramatically differently against each.
  • Transparency. Pick outer = blue (h ≈ 264) and mid2 = orange (h ≈ 50) at matched lightness. Try to find an L for mid1 that makes the composition feel layered.
  • Bottom-heavy weight. Set outer = light, inner = dark. The composition feels grounded. Swap them — outer dark, inner light — and the composition feels lifted.
