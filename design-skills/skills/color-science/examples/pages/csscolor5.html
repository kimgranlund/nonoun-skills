CSS Color 5/6 playground

The four modern CSS color features designers actually use in 2026: color-mix(), relative color syntax, light-dark(), and contrast-color(). Each demo renders the result natively (your browser's CSS engine) alongside the generated CSS — copy and paste.

1. color-mix() in any space

Same two endpoints, mixed in different color spaces. Pick the space and ratio; see the rendered mid-tones and copy the CSS.

2. Relative color syntax

Derive variants from a base color via oklch(from base ...). Common patterns: darken by lightness, desaturate, shift hue.

3. light-dark()

Switch values based on the user's color-scheme preference. The preview below respects your system theme.

Aa
background: light-dark(#fafbfd, #1a1a2e);
color: light-dark(#1a1a2e, #fafbfd);

4. contrast-color()

Let the engine pick black or white text based on the background for WCAG-passing contrast. Pick a background and let the browser decide.

Text using contrast-color() — should auto-pick light or dark.

Note: contrast-color() is CSS Color L6. Browser support lags color-mix and relative syntax — if the text below doesn't change, your browser hasn't shipped it yet.

Why each feature changes how design tokens work

  • color-mix() lets a token system stay small. Instead of authoring 11 stops × 12 hues, author 12 hues plus a "tint with white in oklab at N%" mix rule.
  • Relative color syntax turns "derived" tokens (hover, disabled, focus) into pure CSS expressions of a base — no Sass / Style Dictionary preprocessing.
  • light-dark() halves the number of token declarations needed for dark mode.
  • contrast-color() means the token author never has to ship a paired text color — the browser computes it from the background at use-site.
