# report-brief: Confidence Lexicon

Use this lexicon consistently throughout all briefs. Mixing these terms with lay usage
(e.g., "possibly" to mean "perhaps someday") erodes the signal value.

---

## Analytic confidence levels

These annotate entire judgments — how well the evidence supports the claim overall.

### High confidence
> "We assess with **high confidence** that..."

**Meaning**: Strong, corroborated evidence from multiple independent sources. Logical
chain from evidence to assessment is clear and short. Contradicting evidence is minimal
and accounted for.

**Use when**: Two or more independent primary/secondary sources agree; no significant
contradicting evidence; inference required is minimal.

**Do not use when**: Evidence comes from a single source, no matter how reliable.

---

### Moderate confidence
> "We assess with **moderate confidence** that..."

**Meaning**: Credible evidence with gaps. May rest on a single credible source, or on
multiple sources where one is unreliable. Or: strong evidence that requires more inference
than high-confidence assessments.

**Use when**: Single credible source; or corroborated evidence with one significant gap;
or evidence pattern consistent with the assessment but not conclusive.

---

### Low confidence
> "We assess with **low confidence** that..."

**Meaning**: Sparse or indirect evidence. Significant inferential leaps required.
Assessment may be reasonable but the evidence base is thin.

**Use when**: Primarily inferred from indirect evidence; single unreliable or secondhand
source; evidence pattern is ambiguous.

---

### Cannot assess
> "We **cannot assess** whether..."

**Meaning**: Insufficient information to form a judgment. Use sparingly and only when
true. Always pair with: what evidence would allow assessment.

## Likelihood vocabulary

These qualify individual claims within an assessment — expressing probability of a
specific event or condition.

| Term | Approximate probability | Use for |
|---|---|---|
| **Almost certainly** | >95% | Near-certain outcomes; use sparingly |
| **Highly likely** | 80–95% | Strong evidence pointing one direction |
| **Likely / Probably** | 55–80% | Balance of evidence favors this |
| **Roughly even odds** | 45–55% | Genuinely uncertain; evidence splits |
| **Possibly / May** | 25–45% | Plausible but evidence doesn't favor it |
| **Unlikely** | 10–25% | Evidence points against; cannot rule out |
| **Remote / Highly unlikely** | <10% | Very strong evidence against |

**Anti-pattern**: Using "possibly" as a softener when you actually mean "likely." If
the evidence points one direction, say "likely" — don't hedge to seem humble.

**Anti-pattern**: Using "clearly" or "obviously" in place of a confidence level. These
words beg the question and hide the analyst's actual confidence.

---

## Change vocabulary

When a judgment changes between briefs:

| Phrase | Meaning |
|---|---|
| **Assessment elevated to [level]** | Confidence increased since last brief |
| **Assessment downgraded to [level]** | Confidence decreased since last brief |
| **Key judgment revised** | Direction of assessment changed (not just confidence) |
| **New information** | A gap has been partially or fully filled |
| **Still assessing** | Judgment is pending collection or analysis |

---

## Gap vocabulary

| Phrase | Meaning |
|---|---|
| **Critical gap** | Unknown fact that would change the key judgment if known |
| **Significant gap** | Unknown fact that would change confidence level (not direction) |
| **Informational gap** | Unknown fact that would improve precision but not the judgment |
| **Collection gap** | Information that exists but we don't have access to |
| **Analytical gap** | We have the information but haven't analyzed it yet |

---

## Common errors to avoid

**Overconfidence markers**:
- "It is clear that..." → Use confidence level instead
- "Obviously..." → Remove; state the evidence
- "Certainly..." → Only use with "almost certainly" calibrated meaning

**Underconfidence markers** (false modesty):
- "It's hard to say..." → Either assess or name it as a gap
- "This is just our opinion..." → All analysis is judgment; name the evidence instead
- "We could be wrong..." → Express uncertainty via confidence level, not disclaimers

**False precision**:
- "There is a 67% chance that..." → Probability is meaningful only when based on
  base rates or calibrated models; don't invent precision
- Use the qualitative vocabulary above instead of invented percentages

**Hedge stacking**: Using multiple qualifiers to distance from a claim.
- "It is possible that X might potentially occur in some scenarios" → Pick one: "Possibly X"
